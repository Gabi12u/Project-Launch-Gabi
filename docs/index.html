Funktionen

Alles drin, nichts einzurichten

Kein Gefummel mit Java-Versionen, keine Installer von Drittanbietern, keine kaputten Mod-Ordner. Launch Gabi nimmt dir die Arbeit ab, die sonst zwischen dir und dem Spiel steht.

Getrennte Instanzen

Beliebig viele Installationen nebeneinander, jede mit eigener Version, eigenen Mods, Welten und RAM-Einstellung. Assets werden geteilt statt vervielfacht.

Alle vier Mod Loader

Fabric, NeoForge, Forge und Quilt installieren sich vollautomatisch. Forge und NeoForge patcht Launch Gabi selbst. Ein externer Installer ist nicht nötig.

Java ohne Nachdenken

Vorhandene JDKs werden auf dem System gefunden. Fehlt die passende Version, lädt Launch Gabi ein Temurin-Runtime und verwaltet es selbst.

Modrinth & CurseForge

Eine Suche über beide Plattformen: Mods, Modpacks, Resourcepacks, Shader und Data Packs. Abhängigkeiten kommen automatisch mit.

Prüfung vor dem Start

Loader-Konflikte, Versions-Mismatches, fehlende Abhängigkeiten, doppelte Mods. Für jedes lösbare Problem gibt es einen Knopf, der es behebt.

Backups

Welten, Konfiguration und Mods sichern. Wiederherstellen legt vorher automatisch eine Sicherheitskopie an. Vor Mod-Updates geschieht das auf Wunsch von allein.

Selbstreparatur

Prüft Ordnerstruktur, Client-Jar, Bibliotheken, Assets, Natives und Mod-Dateien per SHA1 und repariert, was defekt ist.

Updates von allein

Der Launcher aktualisiert sich im Hintergrund und installiert beim Beenden. Läuft gerade Minecraft, wartet er.

Hilfe

Häufige Fragen

Welchen Chip hat mein Mac?

Apple-Menü oben links → Über diesen Mac. Steht dort Apple M1/M2/M3/M4, nimm die arm64-Datei. Steht dort Intel, nimm x64.

Linux: das AppImage startet nicht

Erst ausführbar machen. Klick den Befehl an, dann liegt er in der Zwischenablage: chmod +x launch-gabi-*.AppImage

Kommt ein Fehler zu FUSE oder passiert gar nichts, fehlt eine Systembibliothek. Ab Ubuntu 22.04 ist sie nicht mehr vorinstalliert: sudo apt install libfuse2

Warnung „unbekannter Entwickler" beim ersten Start

Launch Gabi ist nicht kostenpflichtig signiert, deshalb warnen Windows und macOS beim ersten Mal. Das betrifft nur den ersten Start.

Windows: Weitere Informationen → Trotzdem ausführen
macOS: Rechtsklick auf die App → Öffnen → im Dialog nochmals Öffnen

Muss ich später neu herunterladen?

Auf Windows und Linux nicht, denn der Launcher aktualisiert sich selbst. Auf macOS schon: dort verhindert die fehlende Signatur die automatische Aktualisierung.

Brauche ich ein Minecraft-Konto?

Zum Spielen ja. Launch Gabi meldet dich per Microsoft-Login an, wie der offizielle Launcher auch. Zum Ausprobieren der Oberfläche gibt es zusätzlich Offline-Profile.
